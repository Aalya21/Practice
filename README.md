# Чат-бот с математическими операциями

Учебный проект по веб-разработке.

## Запуск проекта

1. Скачать проект с GitHub.
2. Открыть папку проекта.
3. Запустить файл `index.html` в браузере.

Также можно использовать расширение Live Server в Visual Studio Code.

## Используемые технологии

- HTML5 — структура чата.
- CSS3 — оформление и адаптивность.
- JavaScript — логика чат-бота и математические операции.

## Команды чат-бота

| Команда | Назначение |
|---|---|
| `/start` | Начать общение |
| `/name: Имя` | Представиться |
| `/numbers: 2, 3` | Передать числа |
| `/set: x = 100` | Создать переменную |
| `/stop` | Завершить общение |
| `/undo` | Удалить последнее сообщение |

## Математические операции

- `+` — сложение.
- `-` — вычитание.
- `*` — умножение.
- `/` — деление.
- `gcd` — наибольший общий делитель.
- `avg` — среднее арифметическое.
- `min` — минимальное число.
- `max` — максимальное число.

## Форматы ввода чисел

- `7, 9, 12`
- `7 9 12`
- `7; 9; 12`
- `10..15`
- `5, 10...15, 20`

## Переменные

Последний результат сохраняется в `ans`.

Для создания собственной переменной используется команда:

`/set: x = 100`

Переменные можно использовать в последующих вычислениях.

## Особенности проекта

- Адаптивный дизайн.
- Максимальная ширина чата 700px.
- Новые сообщения появляются сверху.
- Анимация набора ответа.
- Изменение размера сообщений в зависимости от текста.
- Неактивная кнопка при пустом поле.
- История команд.
- Отмена последнего сообщения.
- Проверка введённых данных.
- Защита от деления на ноль.
- Отсутствие серверной части.
- Запрет на использование `eval()`.
